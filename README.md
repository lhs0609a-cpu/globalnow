# Globalnow

사업자·글로벌 CEO·투자자를 위한 세계 상황 모니터와 의사결정 도구. Next.js 16 / React 19 / TypeScript / Tailwind CSS 4.

홈에서 기사 언급 지역 지도, 우선 확인 상황, 시장 스냅샷을 확인하고 관심 지역·주제·기업 키워드로 범위를 좁힙니다. 원문 근거와 확인 과제를 검토하고 선택 범위를 브리프로 내보냅니다.

## 실행

~~~sh
npm install
npm run dev
~~~

Windows PowerShell에서 npm.ps1이 차단되면 npm.cmd를 사용합니다. 환경 변수는 .env.local.example을 참고해 .env.local에 설정합니다. 실제 키를 커밋하지 않습니다.

Supabase가 없으면 공개 RSS를 우선 조회하고, 실패 시 샘플임을 표시합니다. 게스트 저장은 해당 브라우저에 보관됩니다. Supabase 설정 시 저장은 인증 계정과 연결되며 news·bookmarks 스키마와 서비스 역할 설정이 필요합니다.

Redis가 없거나 실패하면 최대 200개 항목의 프로세스 캐시를 사용합니다. 동일 키의 진행 중 요청을 프로세스 안에서 합칩니다. 분산 잠금이나 사용자 수용량을 보장하는 구조는 아닙니다.

## 사용자 흐름

- 홈 URL의 country, topic, hours, view, search가 지도·상황 목록에 함께 반영됩니다. 기간은 24·72·168시간입니다.
- 내 모니터는 지역·주제·키워드 중 하나라도 일치하는 기사를 모읍니다. 설정은 브라우저에 저장합니다.
- /brief는 선택 범위의 근거·원문·검토 질문을 표시하며 Markdown으로 내보냅니다.
- /compare에서 3개 지역, /reports에서 산업별 최근 7일 근거를 확인합니다.
- /news의 search와 category는 실제 기사 조회 조건입니다. 더 보기·오류 재시도·저장을 제공합니다.
- /saved에서 근거를 다시 읽고 /settings에서 CSV로 내보냅니다.
- 유머·예측 게임·스트릭·뉴스 DNA·감성 지도는 종료했습니다. 기존 페이지는 이동하고 관련 API는 HTTP 410을 반환합니다.

예약 자동화도 조정했습니다. 유머·커뮤니티 트렌드·이전 브리프 생성·이전 뉴스레터 예약 워크플로를 제거했습니다. 수동 수집기의 기본 작업은 RSS와 시장이며, 기존 형식 생성·발송은 명시적 명령으로만 실행합니다. 새 브리프는 현재 조회 범위에서 생성하는 다운로드 문서입니다.

지도는 최대 400개 기사에서 인식한 36개 지역의 언급을 표시합니다. 매체 소재지, 사건 발생 위치, 국가 위험 점수를 동일시하지 않습니다. 지역·주제 분류는 키워드 규칙이며 의미 기반 사건 군집화나 실제 회사 노출 분석이 아닙니다. 지도 데이터는 public/maps에 포함되어 외부 CDN 요청 없이 표시됩니다.

## 검증

~~~sh
npm run typecheck
npm run lint
node scripts/check-cache.mjs
npx playwright install chromium
npm run build
npm run test:ux
~~~

빌드를 완료한 후 브라우저 테스트를 실행합니다. 빌드와 테스트 서버를 동시에 실행하면 변경 중인 .next 자산으로 잘못된 실패가 생길 수 있습니다. 테스트는 전용 포트 3107의 프로덕션 서버를 사용하며 기존 서버를 재사용하지 않습니다.

테스트는 고정 API 응답으로 검색·필터·페이지 추가·오류 복구·저장·모바일 메뉴·대화상자와 상황 분류·관심 설정·브리프 다운로드·국가 비교·산업 필터·종료 경로·반응형·두 테마의 자동 접근성을 확인합니다. 결과는 playwright-report, 화면은 artifacts/ux에 생성됩니다. 실제 외부 API, 인증 계정, 운영 부하는 별도 검증이 필요합니다.

## 리서치와 측정

[의사결정 도구 재설계 보고서](docs/decision-intelligence-strategy.html)에 제품 정의, 기능 유지·강화·교체·제거, 전문 도구의 원문 근거, 데이터 계약과 운영 조건을 기록했습니다. 원본은 docs/research/decision-intelligence-strategy.md이며 node scripts/render-decision-report.mjs로 HTML을 생성합니다.

[이전 UX·UI 개선 연구](docs/ux-review-2026-09-08.html)는 검색·저장·접근성 결함을 다룬 과거 기록입니다. 제품의 현재 목적과 홈 구조는 의사결정 도구 재설계 보고서를 기준으로 합니다.

뉴스·저장 흐름은 globalnow:analytics CustomEvent를 제공합니다. 외부 전송·영구 수집·세션 식별은 구현하지 않았습니다. 상황판의 추가 과업 지표와 운영 수집기는 별도 연결해야 합니다. 실제 이탈률·개선율·동시 접속 1만 명 수용 여부는 측정하지 않았습니다.
